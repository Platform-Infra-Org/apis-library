    ‏API של השגיאות¶

    שתי משפחות של חריגות טיפוסיות.

    שגיאות של מחברים¶

    ה-clients של המחברים מעלים אותן כש-status_code >= 400. מחלקת הבסיס ExternalServiceError יורשת מ-fastapi.HTTPException, כך שהעלאה שלה בתוך נתיב FastAPI הופכת ישירות לתשובת HTTP. ייבאו מ- tashtiot_apis_library.connectors.errors (או את הבסיס ואת תת-המחלקות מהחבילה הראשית):

    from tashtiot_apis_library.connectors.errors import (
    ExternalServiceError,
    ArgoCDError,
    GitError,
    VaultError,
    AWXError,
)

    שגיאות אימות¶

    מנגנון האימות הנכנס/היוצא מעלה אותן. ייבאו מ-tashtiot_apis_library.fastapi_template.errors (זמינות גם מהחבילה הראשית):

    from tashtiot_apis_library.fastapi_template.errors import AuthConfigError, TokenError, SSOError

    AuthConfigError ¶

    Bases: RuntimeError

    Raised at startup when authentication is enabled but the verification material is missing or ambiguous. Surfacing this during app creation makes misconfiguration fail fast instead of on the first request.

    TokenError ¶

    TokenError(detail: str)

    Bases: Exception

    Internal token-level failure (missing, malformed, expired, bad signature, or failing claim validation).

    Carries a public-safe detail string for the 401 response body. Raw PyJWT exception text is never propagated to clients.

    detail instance-attribute ¶

    detail = detail

    SSOError ¶

    SSOError(detail: str)

    Bases: Exception

    Outbound token-acquisition failure when requesting a token from the SSO provider via the client_credentials grant (non-2xx response, malformed body, or a network/transport error).

    Carries a detail string describing the failure for logging/propagation.

    detail instance-attribute ¶

    detail = detail
