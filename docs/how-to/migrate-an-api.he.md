# הסבת API לגרסה הנוכחית של הספרייה {#migrate-an-api-to-the-current-library-version}

השתמשו בפרומפט הזה עם סוכן קוד מבוסס AI (‏Claude Code, ‏Codex, …), והריצו אותו **בתוך המאגר של
ה-API**, כדי להעביר את ה-API לשחרור הנוכחי של `tashtiot-apis-library` ול[תקני ה-API](../reference/api-standards.md).

הפרומפט בוחר קודם אחד משני מצבים:

| מצב | מתי | תוצאה |
|---|---|---|
| **A: שדרוג** | ה-API כבר משתמש בספרייה, בגרסה ישנה יותר | השינוי הבטוח הקטן ביותר. מיישם את הערות השדרוג הספציפיות לגרסה ותיקונים שלא שוברים תאימות. החוזה הציבורי נשמר, וסטיות שתיקונן שובר תאימות רק מדווחות. |
| **B: כתיבה מחדש** | ה-API לא משתמש בספרייה, או שאתם רוצים כתיבה מחדש מלאה | ה-API נבנה מחדש על הספרייה לפי התקנים המלאים (`{metadata, spec}`, מחברים, async, אימות, Remote Config אם צריך). הוא יוצא כגרסה ראשית (major) חדשה. |

## איך משתמשים בו {#how-to-use-it}

1. העתיקו את הפרומפט שלמטה (בעזרת כפתור ההעתקה), או קחו אותו מ-
   [`prompts/migrate-api.md`](https://github.com/Platform-Infra-Org/apis-library/blob/master/prompts/migrate-api.md) במאגר של הספרייה.
2. הריצו אותו במאגר של ה-API, על branch חדש. לפני המיזוג, עברו על המצב שהסוכן בחר ועל רשימת
   "Needs a decision" שלו.

!!! note
    הפרומפט מתעדכן עם כל שחרור של הספרייה, ולכן קחו תמיד את העותק העדכני. גרסת היעד מצוינת בראש
    הפרומפט.
